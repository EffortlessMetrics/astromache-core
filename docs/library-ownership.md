# Library ownership

EffortlessMetrics/astromache-core owns the reusable `astromache` package. EffortlessMetrics/astromache is the small neutral publication starter. EffortlessMetrics/still-core owns `@effortlessmetrics/still`, while EffortlessMetrics/still is the small neutral service-site starter. Package imports remain stable.

Offline integrity/cache/lifecycle belongs independently to https://github.com/EffortlessMetrics/astro-offline. Static search remains independently owned by EffortlessMetrics/static-search. The starters pin exact unpublished archives and do not claim these expanded versions exist on npm. Private sites remain sibling consumers; their content and Git history are excluded.
